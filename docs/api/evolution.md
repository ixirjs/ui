# Family evolution decisions

Every row retains all baseline exports/types and their members, not only the examples named here.
These are design decisions from source/type inspection. They are **not** proof that every member's
runtime contract has been characterized. Shared rules apply per prop/method through the inventory;
new or changed members require the individual review card in [the policy](./README.md).
See [member-level reviews](./member-review.md) for the inspected Kernel/Input tranche and its
explicitly remaining coverage gaps.

| Facade         | Today: preserve                                                                | Tomorrow: extension path / trap                                                                                                             |
| -------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| accordion      | Callable Accordion, AccordionItem parts, value/values, factories and callbacks | Additional selection/navigation policy must preserve single/multiple semantics and no-op callback gating                                    |
| alert          | Parts, disabled/dismissal state, factory and snippets                          | New alert presentation through presets; never repurpose native callbacks                                                                    |
| avatar         | Image/fallback rendering and props                                             | New loading/fallback choices are opt-in; preserve current fallback timing                                                                   |
| badge          | Props, children/snippet shape, preset selectors                                | New visual variants belong to application augmentation, not library unions                                                                  |
| breadcrumb     | Existing parts and augmentation interfaces                                     | Alternate separators/overflow coexist; keep link semantics                                                                                  |
| button         | Native attributes, render props, augmentation                                  | New library props must not capture existing consumer variant/base props                                                                     |
| calendar       | Date/range/start/end, pivote, limits, factory, day model                       | Locale/time-zone additions are opt-in; keep Date representation and pivote spelling                                                         |
| card           | Namespace/direct parts, factory, snippet CardBond, getBond identity            | Retain structural class return type and factory; no wrapper or narrowed handle. New rendering feature must not change current literal parts |
| checkbox       | Checked binding, native and semantic callbacks, snippets                       | New states cannot reinterpret current booleans or event ordering                                                                            |
| chip           | Chip and ChipCloseButton, dismiss interaction, snippets                        | New close presentation preserves cancellation and native events                                                                             |
| collapsible    | Header/body/indicator, binding, factory, motion                                | New disclosure policy remains optional; keep current lifecycle channels                                                                     |
| combobox       | Query/custom selections, selected labels, callbacks, family interface          | Independent declared state contract contains implementation changes; preserve arrays, object identity and root-owned disposal               |
| container      | Existing element, props and snippet presentation                               | Layout variants via presets; no wrapper migration                                                                                           |
| context-menu   | Pointer anchor, menu parts, open state and augmentation                        | Additional trigger policy is opt-in; preserve keyboard/accessibility behavior                                                               |
| datagrid       | Row/column/cell APIs, string selection IDs, sorting, row data, factories       | Data-backed/windowed sources must preserve identity, generics and factory substitutes; do not remove renderer capabilities for speed        |
| date-picker    | Date/range selection, calendar subpickers, popup contract                      | New formats/locales do not replace Date values or existing picker commands                                                                  |
| dialog         | Modal parts, open callback, factory, focus/portal ownership                    | New modal policies preserve default focus, containment and dismissal                                                                        |
| divider        | Element attributes and presentation                                            | Orientation/style extension through existing props/presets                                                                                  |
| drawer         | Drawer parts and Slideover-named types, factory and motion                     | Preferred naming may add aliases; never remove existing type names                                                                          |
| dropdown-menu  | Parts, checked/item metadata, callbacks, menu state                            | New item behaviors retain current metadata and cancellation; no replacement collection protocol                                             |
| element        | HtmlElement/SvgElement, as/base, motion and lifecycle props                    | New renderer strategy must preserve all accepted channels, merge order and forwarding                                                       |
| form           | Callable Form, Field namespace, validation sources, native submit              | Provider integrations use ValidationSource; retain native-submit timing and renderless behavior                                             |
| form/field     | Existing nested subpath and Field types                                        | Keep both form entry routes; optional metadata must not alter field error routing                                                           |
| icon           | Current content/snippets, attributes and rendering                             | Alternative icon sources via existing composition; no mandatory icon provider                                                               |
| image          | Native image props and loading behavior                                        | New fallback/loading options do not change current defaults                                                                                 |
| input          | All controls, aliases, parsed value channels and factory                       | New formats add controls or optional policies; preserve existing value/date/number/files/checked channels                                   |
| kbd            | Kbd, Shortcut and their props                                                  | Platform notation can be opt-in; keep current formatting                                                                                    |
| label          | Native labeling, content and render props                                      | Extra presentation does not replace for/id semantics                                                                                        |
| lazy           | Existing deferred rendering and children contract                              | New scheduling choice preserves current loading and teardown semantics                                                                      |
| link           | Native navigation and renderer contract                                        | New routing integration is optional; do not require a router                                                                                |
| list           | Namespace/direct parts, class/preset behavior                                  | Extra item policy must not silently activate another family's preset fallback                                                               |
| pagination     | Parts, current page state and factory                                          | Unknown totals/server paging require opt-in semantics, not reinterpretation of current counts                                               |
| popover        | Positioning, open callbacks, root-owned state                                  | Independent state signatures; preserve current anchor/portal defaults                                                                       |
| popover-dialog | Existing fused composition and family view                                     | Internal popup/modal composition can change behind the same parts and containment behavior                                                  |
| portal         | Portal/Portals/ActivePortal/Teleport/PortalSurface/ZLayer and target types     | Additional targets/bands preserve existing precedence and named layer relationships                                                         |
| progress       | Linear/circular values and presentation                                        | Additional modes preserve current range and ARIA output                                                                                     |
| qr-code        | Current props and optional QR peer dependency                                  | Alternate encoder cannot become a mandatory dependency for unrelated consumers                                                              |
| radio          | Radio and RadioGroup, values and snippet state                                 | New item presentation preserves grouping, focus and selection behavior                                                                      |
| root           | Provider/root portal IDs and children                                          | New scope defaults cannot change nested overlay targets                                                                                     |
| scrollable     | Viewport/content/track/thumb, factory and pointer behavior                     | New axes/devices retain scrolling and cleanup; use existing presentation seams                                                              |
| select         | Generic root props, arrays/string state commands, options, labels, query       | Keep existing generic defaults; data-backed navigation independent of mounted items; do not silently tighten values to strings              |
| sidebar        | Existing parts/state and animation helper                                      | New layout policy keeps existing bindings and motion contracts                                                                              |
| slider         | Value callbacks, thumb/track snippets and resolved props                       | Multi-thumb or scale changes require separate optional semantics; retain keyboard/ARIA behavior                                             |
| stack          | Root/item and factory composition                                              | New layout/window policy does not change bindable state or child ownership                                                                  |
| stepper        | Stepper/Step, navigation and factories                                         | Validation/async navigation is opt-in; retain current synchronous commands                                                                  |
| swatch         | Current color/presentation props                                               | New color representations coexist rather than replace current accepted values                                                               |
| switch         | Checked state and thumb snippet                                                | New visual variants preserve boolean state and resolved snippet attrs                                                                       |
| tabs           | Tabs/Tab parts, bindings, presets and factories                                | Lazy panels/additional activation policy are opt-in; preserve default activation and ARIA                                                   |
| textarea       | TextareaInput/TextareaControl aliases, value and state                         | New sizing/formatting options preserve aliases and native input behavior                                                                    |
| toast          | Toast/Toaster, queue/options, duration, close reasons and factory              | New queue policies preserve current IDs, dismissal, timing and cleanup                                                                      |
| tooltip        | Hover profile, parts, delay/open behavior, family interface                    | New trigger policy must not silently alter current hover/focus timing                                                                       |
| tree           | Recursive state, factory, per-slot presets and selection                       | New data sources/windowing preserve hierarchy, seeded identity and cross-node navigation                                                    |

## Cross-family interfaces

| Entry / surface             | Today                                                                                    | Tomorrow                                                                                             |
| --------------------------- | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Package root                | Curated values/types, setPreset, createVirtual                                           | Additive exports; no forced subpath migration                                                        |
| preset                      | Closed records, keys, fallback/layer composition, global installation and contextual set | Optional record fields do not reinterpret attrs; preserve augmentation and request isolation         |
| shared                      | Kernel plus model factories and motion primitives                                        | Implementation must satisfy independently owned contracts; compile and run external authoring        |
| utils                       | cn, defineVariants, isBrowser and types                                                  | No expanded generic utility toolkit without demonstrated need                                        |
| experimental                | Concrete classes and canonical popup authoring                                           | Visible reviewed changes; preserve any contracts reachable through stable surfaces                   |
| root.css                    | Published stylesheet path                                                                | Keep path and documented tokens; visual changes require review beyond declaration snapshots          |
| Callback context            | value plus event/bond/reason metadata                                                    | Optional additions; keep ordering, identity and native event semantics                               |
| Prop augmentation           | Interface merging and \*ExtendProps routes                                               | Keep canonical declarations and both routes; do not replace interfaces with aliases                  |
| VirtualOptions/Virtualizer  | Stable keys, count/version tracking, three spreads, pinned item                          | New layout modes remain optional; preserve vertical default, SSR seed and active-descendant presence |
| Peer/toolchain requirements | Current package peer ranges; installed Svelte/TypeScript rehearsal                       | Validate the claimed minimums before raising requirements or widening support claims                 |
